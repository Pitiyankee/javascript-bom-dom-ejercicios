# BOM y DOM con JavaScript

Prácticas de JavaScript en el navegador: el BOM (`window`, `navigator`, `location`, `history`, almacenamiento, temporizadores) y el DOM (selección, recorrido, creación y modificación de nodos, eventos, formularios).

Cada ejercicio es una página HTML con su propio archivo JavaScript.

- `bom/` — B1 a B10: idioma y pantalla, diálogos, URL, temporizadores, `localStorage` y `sessionStorage`, historial, `matchMedia`, `performance` y portapapeles.
- `dom/` — D1 a D10: selección, colecciones vivas y estáticas, delegación de eventos, recorrido recursivo, formularios y una lista de tareas persistente.

## Cómo ejecutarlo

Abre la carpeta en WebStorm y lanza `index.html` en el navegador. Los ejercicios de BOM se ven en la consola (F12). El portapapeles (B10) necesita contexto seguro: `localhost` o `https`.
